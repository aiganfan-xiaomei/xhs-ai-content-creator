# 10种配图风格目录

用户可单选或组合多种风格。每种风格含：适用场景、视觉特征、Prompt关键词、GitHub来源。

---

## 风格1：真实生活方式摄影（默认）
**适用**：工具测评、办公场景、人物出镜、账号日常
**视觉特征**：真人/真实场景、暖光、浅景深、小红书生活方式感、4K照片质感
**Prompt关键词**：photorealistic, warm soft lighting, shallow depth of field, cozy modern desk, lifestyle photography, 4K high quality
**配色**：暖色调，紫蓝点缀，米色/木色桌面
**构图**：人物偏左，电脑屏幕朝右，桌面有饭盒/奶茶/植物

---

## 风格2：白板手绘风
**来源**：github.com/geeklee/srt-whiteboard-animation
**适用**：教程拆解、知识科普、步骤说明、概念解释
**视觉特征**：暖米黄纸张底(#F5EBD7)、深灰素描线条、红/橙/蓝少量点缀、极简手绘、干净留白
**Prompt关键词**：whiteboard hand-drawn illustration, warm cream paper background #F5EBD7, dark gray sketch lines, minimal red orange blue accents, clean composition, generous whitespace, no photography no 3D
**禁忌**：不使用场景文字标签、摄影感、3D效果、复杂纹理
**配色**：#F5EBD7底 + 深灰线 + 红/橙/蓝点缀

---

## 风格3：纸片拼贴风
**来源**：github.com/cyberlesterr/paper-collage-video
**适用**：创意封面、合集盘点、视觉冲击型内容、品牌故事
**视觉特征**：分层纸片切割、撕纸边缘、视差深度感、纸张纹理、拼贴构图、7种纸张转场感
**Prompt关键词**：paper collage art, layered cut paper, torn paper edges, paper texture, parallax depth, mixed media collage, tactile handmade feel
**配色**：可根据主题调整，常用复古色/高饱和撞色
**构图**：多层纸片叠加，前景大元素+背景小元素，阴影制造层次

---

## 风格4：照片+涂鸦混合
**来源**：AI Visual Prompt Cookbook (Playful Mascot Doodle Snapshot / Subway Doodle Photo Hybrid)
**适用**：趣味测评、场景化分享、年轻化表达、IP形象出镜
**视觉特征**：真实照片底 + 卡通涂鸦叠加 + 手绘标注 + 贴纸感元素 + 手写体文字
**Prompt关键词**：photo with doodle overlay, real photograph base, cartoon mascot stickers, hand-drawn annotations, marker scribbles, playful collage, social media style
**配色**：照片原色 + 高饱和涂鸦色（黄/粉/蓝）

---

## 风格5：杂志编辑风
**来源**：AI Visual Prompt Cookbook (Tri Color Hardcut / Soft Analog Future Editorial)
**适用**：深度测评、行业分析、高端工具推荐、品牌向内容
**视觉特征**：干净构图、结构化排版、三色硬切、衬线大标题、留白克制、高级感
**Prompt关键词**：editorial magazine layout, clean composition, tri-color hardcut, serif typography, minimal design, sophisticated layout, generous whitespace
**配色**：黑白为主 + 1个强调色（钴蓝/朱红/墨绿）

## 风格6：Y2K废土拼贴

**适用**：故事型内容、角色介绍、戏剧性场景、二次元向用户
**视觉特征**：漫画墨线、半色调网点、技术面板、注释栏、奶油色边距、黑白+单强调色
**Prompt关键词**：manga dossier style, ink illustration, halftone shading, technical panels, annotation rails, cream margins, black white plus one accent color, comic book aesthetic
**配色**：黑白 + 深红/钴蓝强调色

## 风格8：Riso印刷风
**来源**：AI Visual Prompt Cookbook (Loose Scribble Riso Print)
**适用**：文艺向内容、设计类工具、审美型账号、小众推荐
**视觉特征**：摇摆轮廓、套印错位、手写边注、可见纸张纹理、有限色板、手工感
**Prompt关键词**：risograph print style, wavering contours, overprint misregistration, handwritten margins, visible paper grain, limited color palette, handmade print feel
**配色**：2-3色套印（常用荧光粉+蓝+黄）

**适用**：IP形象展示、可爱风内容、工具拟人化、低龄向/泛用户
**视觉特征**：可爱3D角色、柔和阴影、马卡龙配色、玩具质感、圆润造型、皮克斯风
**Prompt关键词**：3D cartoon render, cute character, soft shadows, pastel colors, toy-like texture, pixar style, rounded shapes, glossy materials, 4K octane render
**配色**：马卡龙色系（粉/紫/蓝/黄）

## 风格10：赛博科技风
**适用**：硬核技术工具、AI Agent、编程/开发类、未来感内容
**视觉特征**：霓虹光效、全息UI界面、深色背景、发光元素、故障艺术、未来感
**Prompt关键词**：cyberpunk tech aesthetic, neon glow, holographic UI interface, dark background, glowing elements, glitch art, futuristic, hologram, data visualization overlay
**配色**：黑/深蓝底 + 霓虹青/品红/黄

---

## 风格组合建议
- 封面用风格1/3/6/10（吸睛）
- 内页教程用风格2/4/7（清晰）
- 数据/对比用风格5/8（高级）
- 结尾引导用风格9（可爱）
- 同一篇内建议主风格1种 + 辅助风格1种，不超过2种

## 风格选择决策
根据话题自动推荐：
- 教程/步骤类 → 风格2白板手绘
- 工具测评 → 风格1真实摄影
- 创意/合集 → 风格3纸片拼贴
- 趣味/年轻 → 风格4照片涂鸦 或 风格6 Y2K
- 深度/行业 → 风格5杂志编辑
- 二次元/故事 → 风格7漫画档案
- 文艺/设计 → 风格8 Riso印刷
- IP/可爱 → 风格9 3D卡通
- 技术/硬核 → 风格10赛博科技
